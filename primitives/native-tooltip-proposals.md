# Native Tooltip Proposals

**Role:** watchlist for moving tooltip timing, positioning, accessibility and input handling into the browser.

One direction explored by Microsoft Edge is a styleable `::tooltip` pseudo-element for browser-native title tooltips.

This sits on the same trajectory as:

```text
custom JS tooltip
 -> popover + anchor positioning
 -> interestfor + popover=hint
 -> potentially native styleable tooltip UI
```

## Status

Proposal/watchlist only. Do not use in production code yet.
