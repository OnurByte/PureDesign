Where does temporary UI state live?
In the browser-native primitive: disclosure state, checked state, focus state, popover state, or URL fragment state.
Where does durable state live?
On the server. Links and forms produce HTTP requests; the response returns authoritative HTML.
What happens when newer CSS is unsupported?
Polish should disappear, not functionality. Progressive enhancement is part of the component contract.
